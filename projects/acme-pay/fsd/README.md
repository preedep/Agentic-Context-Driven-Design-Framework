# acme-pay — FSD Folder

Store all Functional Specification Documents for the acme-pay project here.

## Naming Convention

```
<feature-slug>-fsd.md          ← authored FSD
<feature-slug>-fsd-review.md   ← AI review report of the FSD
```

## Template

Use `core/fsd/FSD_TEMPLATE.md` as the starting point for every new FSD.

## Example

```
projects/acme-pay/fsd/
├── payment-gateway-fsd.md
├── payment-gateway-fsd-review.md
├── refund-processing-fsd.md
└── account-management-fsd.md
```
