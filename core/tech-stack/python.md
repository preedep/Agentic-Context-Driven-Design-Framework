## Router → Service → Repository Pattern (Python / FastAPI Implementation)

```python
# Router — thin HTTP layer
@router.post("/payments", response_model=PaymentResponse)
async def create_payment(
    req: CreatePaymentRequest,
    service: PaymentService = Depends(get_payment_service),
):
    return await service.create_payment(req)

# Service interface (Protocol)
class PaymentService(Protocol):
    async def create_payment(self, req: CreatePaymentRequest) -> PaymentResponse: ...

# Service implementation — business logic
class PaymentServiceImpl:
    def __init__(self, repo: PaymentRepository) -> None:
        self._repo = repo

    async def create_payment(self, req: CreatePaymentRequest) -> PaymentResponse:
        validate(req)                           # validate step
        saved = await self._repo.save(req)      # persist step
        await publish_event(saved)              # publish step
        return PaymentResponse.model_validate(saved)

# Repository — data access only
class PaymentRepositoryImpl:
    async def save(self, req: CreatePaymentRequest) -> Payment: ...
```

## DO NOT

- Do not use `print()` for logging — use the structured logger
- Do not put business logic in route handlers — delegate to service layer
- Do not raise `HTTPException` inside the service layer — raise domain exceptions
- Do not use raw SQL string formatting — always use parameterized queries
- Do not expose ORM / DB models directly in API responses — always map to Pydantic schemas
- Do not use mutable default arguments in function signatures
